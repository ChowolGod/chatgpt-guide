# 이미지 활용

> 상태: 초안

## 이번 장에서 할 일

이미지를 읽는 일과 새로 만드는 일을 구분하고, 목적에 필요한 시각 조건을 설명한 뒤 결과를 검토합니다.

## 이미지로 할 수 있는 일

### 이미지를 입력할 때

- 사진 속 사물이나 장면 설명하기
- 화면 캡처에서 문제 지점 찾기
- 표나 도표의 흐름을 쉬운 말로 설명하기
- 두 디자인의 차이 비교하기
- 포스터나 문서 이미지에서 정보 추출하기

### 이미지를 만들 때

- 발표자료의 개념 이미지 만들기
- 캠페인 아이디어의 시안 만들기
- 글의 대표 이미지나 삽화 만들기
- 제품 배치나 공간 분위기를 미리 시각화하기
- 같은 아이디어의 여러 스타일 비교하기

## 분석할 때는 무엇을 봐야 하는지 말하세요

```text
첨부한 행사 포스터를 처음 보는 참가자 관점에서 검토해줘.
행사명, 날짜, 장소, 신청 방법을 정확히 옮긴 뒤
5초 안에 알아보기 어려운 정보를 찾아줘.
작아서 읽을 수 없는 글자는 추측하지 말고 표시해줘.
```

“이 이미지 어때?”보다 관점과 확인 항목을 지정한 요청이 유용합니다.

## 이미지 생성 요청의 여섯 요소

1. **목적:** 어디에 사용할 이미지인가
2. **주제:** 무엇이 중심인가
3. **상황:** 어디에서 무엇을 하는가
4. **분위기:** 밝음, 차분함, 신뢰감 등
5. **구도:** 가로·세로, 여백, 시선, 배치
6. **제외할 것:** 원하지 않는 글자, 로고, 요소

```text
사내 교육자료 표지에 쓸 가로형 이미지를 만들어줘.
비전공자 세 명이 책상에서 AI와 함께 업무를 정리하는 장면이야.
밝고 현실적이며 부담 없는 분위기로 표현해줘.
왼쪽에 인물을 두고 오른쪽 절반은 제목을 넣을 빈 공간으로 남겨줘.
이미지 안에는 글자, 로고, 워터마크를 넣지 말아줘.
```

스타일 이름을 길게 나열하기보다 사용 목적과 배치 이유를 먼저 설명하세요.

## 글자는 나중에 넣는 방법도 있습니다

이미지 안의 작은 문구나 정확한 숫자는 틀리거나 흐려질 수 있습니다. 배경과 그림만 만든 뒤, 제목과 본문은 발표자료나 디자인 도구에서 직접 넣으면 수정과 검수가 쉬워집니다.

## 결과가 아쉽다면 한 번에 하나씩 고치세요

```text
전체 분위기와 인물은 유지하고,
오른쪽 빈 공간만 조금 더 넓혀줘.
다른 요소는 바꾸지 말아줘.
```

무엇을 유지하고 무엇만 바꿀지 지정하면 수정 방향이 선명합니다. 큰 변화가 필요하면 이전 결과를 억지로 고치기보다 새 시안을 만드는 편이 나을 수도 있습니다.

## 참고 이미지를 줄 때

참고 이미지의 역할을 설명하세요.

```text
A 이미지에서는 따뜻한 색감을 참고하고,
B 이미지에서는 넓은 여백의 구도만 참고해줘.
인물과 로고는 그대로 복제하지 말고 새 장면으로 만들어줘.
```

참고 자료를 사용할 권리가 있는지 확인하고, 실제 인물이나 조직의 로고를 다룰 때는 사용 규정을 따릅니다.

## 이미지 분석에서 특히 주의할 것

- 작은 글자와 저해상도 화면
- 복잡한 표의 행과 열
- 정확한 개수 세기
- 의료 영상이나 안전 상태 판단
- 사진만으로 신원, 의도, 감정을 단정하는 일
- 이미지에 보이지 않는 앞뒤 상황을 추측하는 일

```text
관찰한 사실과 추정한 내용을 나눠서 적어줘.
확대가 필요하거나 확인할 수 없는 영역도 알려줘.
```

## 사용할 수 있는 결과인지 확인하세요

- 필요한 가로세로 비율과 해상도인가?
- 제목이나 로고를 넣을 여백이 충분한가?
- 손, 글자, 물체의 형태가 자연스러운가?
- 사실을 표현한 지도·제품·복장 등이 정확한가?
- 저작권, 초상권, 상표와 조직 규정에 문제가 없는가?
- 특정 집단을 고정관념으로 표현하지 않았는가?

## 직접 해보기

### 과제

업무에서 사용할 표지 이미지 하나를 만드세요. 첫 결과에서 가장 중요한 수정 사항 하나를 고른 뒤, 유지할 요소와 바꿀 요소를 나눠 후속 요청을 해보세요.

### 완료 체크

- [ ] 이미지의 사용 목적과 대상을 적었다.
- [ ] 주제, 분위기, 구도, 여백을 지정했다.
- [ ] 이미지 안에 꼭 필요한 글자만 남겼다.
- [ ] 관찰과 추정을 구분해 검토했다.
- [ ] 저작권·초상권·상표·조직 규정을 확인했다.
- [ ] 실제 사용 화면에 넣어 크기와 가독성을 확인했다.
