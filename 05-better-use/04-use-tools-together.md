# 여러 도구 함께 사용하기

> 상태: 초안

## 이번 장에서 할 일

검색, 파일, 문서, 표, 발표자료 같은 수단을 하나의 업무 흐름에 연결하고, 단계별 검토와 승인 지점을 정합니다.

## 도구가 아니라 결과에서 시작하세요

“어떤 기능을 써볼까?”보다 “무엇을 완성해야 하나?”를 먼저 묻습니다.

```text
최종 결과: 신규 협력사 3곳의 비교 보고서
필요한 근거: 최신 공식 정보와 내부 요구사항
중간 산출물: 출처 목록 → 비교표 → 추천안 → 1쪽 보고서
```

이제 각 단계에 필요한 수단을 고릅니다.

| 업무 단계 | 필요한 수단 | 사람이 확인할 것 |
|---|---|---|
| 후보 조사 | 웹 검색 | 공식 출처와 확인 날짜 |
| 내부 기준 파악 | 요구사항 파일 | 최신 버전과 필수 조건 |
| 항목 비교 | 표 | 단위, 빈칸, 계산식 |
| 결론 작성 | 문서 | 근거와 추천 기준 |
| 공유 | 이메일·발표자료 | 수신자, 공개 범위, 최종 표현 |

## 먼저 작업 지도를 요청하세요

```text
아직 실행하지 말고 이 일을 단계별로 설계해줘.
각 단계마다 필요한 자료와 수단,
만들 결과, 사람이 확인할 항목을 표로 적어줘.
외부 시스템을 바꾸거나 메시지를 보내는 단계는
반드시 실행 전에 내 승인을 받도록 표시해줘.
```

계획을 보고 불필요한 단계와 권한을 줄인 뒤 실행합니다.

## 연결할 때 지켜야 할 네 가지 원칙

### 1. 한 단계의 결과를 다음 단계의 입력으로 만드세요

검색 결과를 곧바로 보고서로 만들면 어디서 잘못됐는지 찾기 어렵습니다. 먼저 출처표를 만들고, 검토한 출처표만 비교 분석에 사용합니다.

### 2. 원본과 중간 산출물을 구분하세요

```text
원본: 회사 공식 가격표, 내부 요구사항 문서
중간 산출물: 출처 요약표, 평가 점수표
최종 산출물: 추천 보고서
```

중간 요약을 원본처럼 취급하지 않도록 파일명과 표에 출처를 남깁니다.

### 3. 필요한 접근 권한만 사용하세요

연결된 도구는 채팅 밖의 파일이나 업무 시스템에 접근할 수 있습니다. 읽기만 필요한 일에 수정 권한을 주지 말고, 개인정보와 기밀정보가 다른 도구로 이동하는 범위를 확인하세요.

### 4. 되돌리기 어려운 행동 전에 멈추세요

메시지 발송, 게시, 결제, 삭제, 대량 수정은 초안 생성과 다릅니다. 반드시 대상과 내용을 사람이 확인한 뒤 실행합니다.

```text
조사와 초안 작성까지만 진행해줘.
메일 발송, 파일 공유, 시스템 변경은 하지 말고
실행 직전에 무엇이 바뀌는지 보여준 뒤 기다려줘.
```

## 실전 흐름: 조사에서 발표자료까지

### 1단계: 조사

```text
공식 출처를 우선해 후보 5곳을 조사해줘.
가격과 기능은 확인 날짜와 링크를 함께 기록해줘.
```

### 2단계: 내부 조건과 대조

```text
첨부한 요구사항 파일에서 필수 조건과 선택 조건을 분리해줘.
방금 만든 후보 목록과 대조하되, 아직 점수는 매기지 마.
```

### 3단계: 비교표

```text
검토가 끝난 정보만 사용해 비교표를 만들어줘.
확인되지 않은 값은 0점으로 처리하지 말고 '확인 필요'로 남겨줘.
```

### 4단계: 추천안

```text
추천 기준과 가중치를 먼저 보여줘.
내가 승인한 뒤 1순위와 대안을 작성해줘.
추천을 바꿀 수 있는 조건도 함께 적어줘.
```

### 5단계: 공유 자료

```text
승인된 비교표와 추천안을 바탕으로
의사결정자용 5장 발표자료 초안을 만들어줘.
새로운 사실은 추가하지 말고 각 장에 출처를 표시해줘.
```

## 중간 산출물 검토표

| 단계 | 멈춰서 확인할 질문 |
|---|---|
| 자료 수집 | 빠진 자료와 접근하지 못한 자료는 무엇인가? |
| 정리 | 원문과 요약이 일치하는가? |
| 계산 | 단위와 기준 시점이 같은가? |
| 판단 | 사실, 기준, 의견이 구분되는가? |
| 공유 | 대상, 공개 범위, 첨부물이 맞는가? |

## 기능을 찾을 수 없을 때

기능은 요금제, 기기, 지역, 배포 시점과 조직 설정에 따라 다를 수 있습니다. 기능이 보이지 않으면 같은 목적을 더 작은 단계로 처리하세요. 예를 들어 직접 파일을 내려받아 첨부하거나, 검색 결과를 표로 복사해 다음 단계의 입력으로 사용할 수 있습니다.

## 어디까지 믿어야 할까요?

도구가 많아질수록 편리함뿐 아니라 오류와 정보 노출의 경로도 늘어납니다.

- 각 도구가 읽거나 바꿀 수 있는 범위를 확인합니다.
- 단계마다 사용한 자료와 결과를 남깁니다.
- 실패했을 때 어느 단계부터 다시 시작할지 정합니다.
- 외부에 영향을 주는 행동은 사람이 승인합니다.
- 마지막 산출물을 원본 자료와 다시 대조합니다.

## 직접 해보기

### 과제

자료 수집부터 공유 초안까지 이어지는 업무 하나를 고르고, 위 표처럼 단계·수단·산출물·검토 지점을 설계하세요. 실제 실행은 읽기와 초안 작성까지만 해봅니다.

### 완료 체크

- [ ] 최종 결과부터 정의했다.
- [ ] 각 단계의 입력과 출력을 연결했다.
- [ ] 필요한 최소 권한을 확인했다.
- [ ] 사람이 검토하거나 승인할 지점을 표시했다.
- [ ] 외부 변경이나 발송 전에 멈추도록 요청했다.
- [ ] 최종 결과를 원본과 대조했다.
