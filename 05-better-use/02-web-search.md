# 웹 검색

> 상태: 초안

## 이번 장에서 할 일

최신 정보가 필요한 질문을 구분하고, 검색 범위와 출처 기준을 정한 뒤 답변의 주장과 출처가 실제로 맞는지 확인합니다.

## 검색이 필요한 때

- 최근 뉴스나 시장 동향을 알고 싶을 때
- 현재 가격, 일정, 담당자, 지원 기능을 확인할 때
- 법률·정책·규정의 최신 내용을 알아볼 때
- 제품이나 서비스를 비교하고 구매 결정을 준비할 때
- 근거 링크가 필요한 조사 보고서를 만들 때

창작, 문장 다듬기, 내가 제공한 자료 요약처럼 외부 최신 정보가 필요 없는 일에는 검색이 필수가 아닙니다.

## “최신” 대신 기준 시점을 쓰세요

“요즘”, “최근”, “현재”는 사람마다 다르게 이해할 수 있습니다.

```text
2026년 9월 10일 기준으로 조사해줘.
대한민국에서 제공되는 개인용 서비스만 포함해줘.
가격은 원화와 월간 결제 기준으로 비교해줘.
```

날짜, 지역, 대상, 제외 조건을 넣으면 검색 범위가 선명해집니다.

## 출처의 우선순위를 정하세요

모든 검색 결과의 신뢰도가 같지는 않습니다. 보통 다음 순서로 확인하는 것이 좋습니다.

1. 법령, 정부 발표, 회사 공식 문서 같은 원출처
2. 원문 연구, 통계 작성 기관, 공식 데이터
3. 내용을 해설하는 신뢰할 만한 2차 출처
4. 블로그, 커뮤니티, 요약 게시물

```text
공식 문서와 원출처를 우선해줘.
주요 주장마다 바로 확인할 수 있는 링크를 붙여줘.
원출처를 찾지 못했다면 그 사실을 밝혀줘.
```

후기나 실제 사용 경험이 중요한 질문에서는 커뮤니티 자료도 쓸 수 있습니다. 다만 개인 경험과 일반 사실을 구분해서 읽으세요.

## 검색 요청의 기본형

```text
[질문]
우리 팀이 사용할 온라인 설문 도구 3개를 비교해줘.

[범위]
2026년 9월 10일 기준, 한국에서 사용 가능하고
비개발자가 운영할 수 있는 서비스만 포함해줘.

[비교 기준]
가격, 응답 수 제한, 한글 지원, 데이터 내보내기,
개인정보 관련 공식 안내를 비교해줘.

[출처와 결과]
공식 가격표와 도움말을 우선하고,
각 항목에 출처 링크와 확인 날짜를 넣어 표로 작성해줘.
확인할 수 없는 값은 추측하지 말고 '확인 필요'라고 적어줘.
```

## 뉴스는 두 날짜를 확인하세요

- **게시일:** 기사가 공개되거나 수정된 날짜
- **사건 발생일:** 실제 발표나 사건이 일어난 날짜

오래된 사건을 오늘 다시 소개한 기사도 있습니다. “오늘 발표됐다”는 식으로 잘못 이해하지 않으려면 두 날짜를 분리해달라고 요청하세요.

```text
각 항목에 게시일과 실제 사건 발생일을 따로 적어줘.
같은 사건을 반복 보도한 기사는 하나로 묶어줘.
```

## 출처가 서로 다를 때

차이를 억지로 하나의 결론으로 만들지 않습니다.

```text
출처끼리 다른 내용을 주장하면
쟁점, 각 출처의 주장, 근거, 확인 시점,
차이가 생긴 가능한 이유를 표로 보여줘.
확실한 결론이 없다면 그대로 남겨줘.
```

가격이나 기능처럼 자주 바뀌는 정보는 확인 시점이 다르면 모두 맞았을 수도 있습니다.

## 결과를 받은 뒤 세 번 확인하세요

### 1. 링크가 열리는가

링크가 실제 페이지로 연결되는지, 로그인이나 지역 제한 때문에 볼 수 없는지 확인합니다.

### 2. 출처가 주장을 뒷받침하는가

제목만 비슷하고 본문은 다른 이야기를 할 수 있습니다. 중요한 주장 옆의 링크를 열어 문맥을 확인하세요.

### 3. 더 최신 원문이 있는가

개정 공지, 최신 가격표, 정정 기사, 최종 연구가 따로 있는지 살펴봅니다.

## 어디까지 믿어야 할까요?

웹 검색이 있다고 해서 자동으로 사실이 보장되지는 않습니다. 검색 결과가 누락되거나, 오래되거나, 잘못 요약될 수 있습니다.

- 중요한 주장마다 근거 링크를 요구합니다.
- 한 출처에만 의존하지 않습니다.
- 법률·의료·금융 등 중요한 판단은 전문가와 최신 공식 원문을 확인합니다.
- 검색 결과와 자신의 의견을 구분해 달라고 요청합니다.
- 확인할 수 없는 정보는 빈칸으로 남기는 편이 안전합니다.

## 직접 해보기

### 과제

자주 사용하는 제품이나 제도 하나를 골라 오늘 기준의 변화를 조사해보세요. 공식 원문 한 개와 서로 독립된 보조 출처 두 개 이상을 확인합니다.

### 완료 체크

- [ ] 기준 날짜, 지역, 대상을 지정했다.
- [ ] 비교 기준과 제외 조건을 적었다.
- [ ] 원출처를 우선하도록 요청했다.
- [ ] 게시일과 사건 발생일을 구분했다.
- [ ] 주요 링크를 직접 열어 주장과 대조했다.
- [ ] 불확실한 내용을 확정 사실처럼 쓰지 않았다.
