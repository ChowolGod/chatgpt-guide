# PART 5. 더 편하게 활용하기

파일, 웹 검색, 이미지와 여러 도구를 필요한 만큼 더하고, 반복 업무를 재사용 가능한 절차로 바꿉니다.

## 이 Part를 사용하는 방법

새 기능을 많이 쓰는 것이 목표는 아닙니다. 먼저 원하는 결과를 정한 뒤, 그 결과에 꼭 필요한 수단만 선택합니다.

```text
원하는 결과 정하기
→ 필요한 자료와 수단 고르기
→ 작은 단계로 실행하기
→ 결과와 출처 확인하기
→ 재사용 가능한 절차로 남기기
→ 충분히 안정된 부분만 자동화하기
```

기능의 제공 여부와 화면은 요금제, 기기, 지역, 배포 시점, 조직 설정에 따라 달라질 수 있습니다. 메뉴 이름을 외우기보다 **어떤 상황에 어떤 수단이 필요한지**를 익히세요.

## 이 Part에서 계속 사용할 세 가지 질문

1. 이 수단이 없으면 결과를 만들 수 없는가?
2. 사람이 반드시 확인하거나 승인해야 하는 지점은 어디인가?
3. 다음번에도 쓸 수 있도록 무엇을 남겨야 하는가?

**Part 완료 기준:** 업무 목적에 맞는 수단을 선택하고, 사람이 검토할 지점이 포함된 반복 가능한 절차로 정리할 수 있다.
