# 기획서

## 한 문장 정의

비전공자·비개발자가 직접 따라 하며 ChatGPT 활용 원리를 익히고, 마지막에는 자신의 업무 흐름을 설계하게 만드는 DIY 실전 가이드.

## 독자의 출발점

- AI, LLM, 프롬프트 같은 용어를 모른다.
- 코딩 경험이 없다고 가정한다.
- ChatGPT의 가능성과 한계를 아직 구분하지 못한다.
- 하나의 완벽한 질문을 만들어야 한다고 생각할 수 있다.

## 핵심 학습 흐름

1. 할 수 있는 것과 할 수 없는 것을 구분한다.
2. 활용 유형을 업무 문제 중심으로 익힌다.
3. 기본 요청에서 시작해 대화로 결과를 개선한다.
4. 답변을 검증하고 실제 산출물로 완성한다.
5. 배운 원리를 자신의 반복 업무에 적용한다.

## 교육 원칙

- 기능이 아니라 해결할 문제에서 시작한다.
- 전문 용어보다 일상 언어와 예시를 사용한다.
- 첫 프롬프트의 완성도보다 반복 개선 과정을 강조한다.
- 모든 실습은 입력 → 대화 → 검토 → 산출물로 이어진다.
- 정답 예시만 보여주지 않고 실패와 수정 과정도 보여준다.
- 중요한 사실, 개인정보, 회사 정보는 반드시 검증·보호하도록 안내한다.

## 범위

포함: 대화법, 작성·요약·정리·분석·조사, 파일과 데이터 활용, 산출물 제작, 반복 업무 설계, 검증과 안전.

제외: API 개발, 코딩 중심 자동화, 모델 내부 원리의 심화 설명, 특정 직무에만 맞춘 전문 매뉴얼.

## 최종 프로젝트

독자가 자신의 업무 하나를 골라 다음을 완성한다.

1. 업무의 시작 자료와 최종 산출물 정의
2. 사람이 판단할 단계와 ChatGPT에 맡길 단계 구분
3. 단계별 요청 템플릿 작성
4. 검증 기준과 민감정보 처리 원칙 설정
5. 실제 실행 후 회고와 개선
