# 쉬운 용어집

처음 등장하는 용어는 본문에서도 바로 설명하고, 이 문서는 다시 찾아보는 용도로 사용합니다.

| 용어 | 쉬운 설명 | 집필 메모 |
|---|---|---|
| ChatGPT | 사람의 요청을 바탕으로 글, 분석, 아이디어, 산출물 등을 만들어 주는 대화형 AI 도구 | 사람처럼 말하지만 사람처럼 이해하거나 사실을 보장하지는 않음 |
| 프롬프트 | ChatGPT에게 입력하는 질문, 지시, 자료의 묶음 | 가능하면 “요청”을 먼저 사용 |
| 맥락 | 목적, 대상, 배경처럼 일을 이해하는 데 필요한 정보 | 왜 필요한지도 예시로 설명 |
| 출력 형식 | 표, 목록, 이메일, 보고서처럼 결과를 보여주는 모양 | “결과 형태”와 함께 사용 |
| 환각 | AI가 틀린 내용을 그럴듯하게 만들어 내는 현상 | 본문에서는 “그럴듯한 오류”로 먼저 설명 |
| 웹 검색 | 최신 정보나 출처를 찾기 위해 인터넷 자료를 확인하는 기능 | 출처 확인과 함께 가르침 |
| 자동화 | 반복되는 일을 정해진 조건과 순서에 따라 처리하게 만드는 것 | 완전 무인 처리만 뜻하지 않음 |
