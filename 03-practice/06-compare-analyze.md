# 비교하고 분석하기

> 상태: 초안

## 이번 장에서 할 일

여러 대상을 같은 기준으로 비교하고, 결정을 돕는 차이·장단점·추가 질문을 정리합니다.

## 비교 전에 기준부터 맞추세요

비교표가 깔끔해도 기준이 다르면 결론은 잘못될 수 있습니다. 먼저 다음을 정합니다.

- 비교 대상
- 같은 기준으로 비교할 항목
- 각 기준의 중요도
- 사용할 자료와 시점
- 정보가 없을 때 표시하는 방법

## 먼저 해보기

```text
첨부한 세 업체의 제안서를 가격, 도입 기간, 지원 범위, 계약 조건, 주요 위험으로 비교해줘.
각 내용의 출처 페이지를 표시하고, 제안서에 없는 정보는 “제공되지 않음”으로 써줘.
추측으로 빈칸을 채우지 마.
```

## 결과가 아쉽다면

### 기준의 뜻 정하기

```text
“가격”은 초기 비용과 1년 운영 비용으로 나눠줘.
세금 포함 여부와 사용자 수 조건이 다르면 같은 값처럼 비교하지 말고 차이를 설명해줘.
```

### 중요도 반영하기

```text
우리에게는 보안과 도입 기간이 가장 중요하고 가격은 그다음이야.
가중치를 적용하기 전에 적절한 평가 방식을 제안하고 내가 확인할 질문을 해줘.
```

### 근거와 해석 분리하기

```text
제안서에 명시된 사실과 그 사실을 바탕으로 한 네 해석을 구분해줘.
```

### 추가 질문 만들기

```text
현재 자료만으로 결정할 수 없는 항목을 찾고 업체별 확인 질문을 만들어줘.
```

## 점수의 함정

ChatGPT가 10점 만점처럼 정확해 보이는 점수를 만들 수 있지만, 점수 기준과 근거가 없으면 의미가 없습니다.

```text
점수를 매기기 전에 각 점수 구간의 의미를 정의해줘.
자료로 확인할 수 없는 기준은 점수를 주지 말고 “평가 보류”로 표시해줘.
```

정성적인 판단을 억지로 숫자로 바꾸지 않아도 됩니다. `충족 / 일부 충족 / 미확인`처럼 근거를 확인하기 쉬운 표현이 나을 수 있습니다.

## 분석과 추천 구분하기

비교는 차이를 보여주는 일이고, 추천은 우선순위를 적용한 판단입니다.

```text
먼저 사실 비교표를 만들고, 그 아래에 우리 우선순위를 반영한 추천을 별도로 작성해줘.
추천이 달라질 수 있는 가정도 알려줘.
```

## 한 단계 더 해보기

의사결정 문서로 바꿉니다.

```text
이 비교를 부서장용 1쪽 결정 메모로 바꿔줘.
결정할 내용, 핵심 차이, 추천과 이유, 주요 위험, 결정 전 확인 질문의 순서로 작성해줘.
```

## 어디까지 믿어야 할까요?

- 서로 다른 기간, 통화, 단위, 포함 범위를 맞췄는지 확인합니다.
- 최신 자료와 같은 버전을 사용했는지 봅니다.
- 빈칸을 추측으로 채우지 않았는지 확인합니다.
- 추천은 내가 제공한 우선순위에 따른 것인지 검토합니다.
- 중요한 결정은 원문과 담당자의 확인을 거칩니다.

## 직접 해보기

### 과제

실제 선택해야 할 두세 가지 대상을 고릅니다. 비교 기준을 먼저 정의하고 사실 비교표, 미확인 정보, 추천이 달라지는 조건을 만드세요.

### 완료 체크

- [ ] 비교 기준과 뜻을 먼저 정했다.
- [ ] 모든 대상을 같은 기준으로 비교했다.
- [ ] 사실, 해석, 추천을 구분했다.
- [ ] 미확인 정보를 별도로 표시했다.
- [ ] 원자료와 중요 수치를 직접 확인했다.

## 기억할 한 문장

> 좋은 비교는 순위를 빨리 정하는 것이 아니라, 같은 기준과 근거로 차이를 보여주고 남은 질문을 드러내는 일입니다.
