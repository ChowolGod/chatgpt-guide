# 데이터 분석하기

> 상태: 초안

## 이번 장에서 할 일

데이터의 구조와 품질을 먼저 확인하고, 업무 질문에 답하는 분석·차트·인사이트를 만듭니다.

## 분석은 질문에서 시작합니다

“데이터를 분석해줘”라고 하면 눈에 띄는 패턴을 나열할 수 있지만 내 결정에 필요한 답이 아닐 수 있습니다.

```text
이 데이터에서 2026년 1월부터 8월까지 월별 문의량이 어떻게 변했는지 분석해줘.
특히 채널별 증가율과 급격한 변화가 나타난 달을 찾고 싶어.
```

## 준비물

- 원본 데이터 파일
- 행 하나가 뜻하는 것
- 각 열의 의미와 단위
- 분석 기간과 제외 기준
- 답하려는 업무 질문
- 개인정보 제거 또는 가명 처리 여부

## 1단계: 바로 계산하지 말고 구조 확인하기

```text
분석을 시작하기 전에 다음을 확인해줘.
- 시트와 표의 구조
- 행 하나와 각 열의 의미
- 날짜 범위와 단위
- 빈값, 중복, 이상한 값
- 해석이 애매한 열
아직 결론은 내리지 마.
```

데이터 설명이 틀리면 이후 계산도 모두 잘못될 수 있습니다.

## 2단계: 질문과 계산 방법 정하기

```text
목표는 채널별 문의량 변화와 급증 시점을 찾는 것이야.
사용할 지표와 계산 방법을 먼저 제안해줘.
증가율을 계산할 때 분모가 0인 경우의 처리 방법도 알려줘.
```

## 3단계: 분석하고 근거 남기기

```text
확정한 방법으로 분석해줘.
원본 값, 계산식, 결과를 구분하고 핵심 수치는 어느 시트와 열에서 나온 것인지 표시해줘.
```

## 결과가 아쉽다면

### 그룹별 차이 보기

```text
전체 평균만 보지 말고 지역과 고객 유형별로 나눠 같은 패턴이 나타나는지 비교해줘.
```

### 이상값 확인하기

```text
결과에 큰 영향을 주는 이상값을 찾고, 포함했을 때와 제외했을 때 결과를 비교해줘.
제외 여부는 임의로 결정하지 마.
```

### 차트 제안받기

```text
이 질문에 가장 적합한 차트 하나를 제안해줘.
가로축, 세로축, 구분 항목과 이 차트가 적합한 이유를 설명해줘.
```

### 해석의 한계 적기

```text
이 데이터만으로 말할 수 있는 것과 말할 수 없는 것을 구분해줘.
결론을 바꿀 수 있는 누락 데이터와 가정을 알려줘.
```

## 상관관계와 원인을 구분하기

두 값이 함께 움직였다고 해서 하나가 다른 하나의 원인이라는 뜻은 아닙니다.

```text
관찰된 관계를 설명하되 원인으로 단정하지 마.
가능한 다른 설명과 원인을 확인하기 위해 필요한 추가 데이터를 제안해줘.
```

## 한 단계 더 해보기

분석을 보고서로 바꿉니다.

```text
분석 결과를 부서장용 1쪽 보고서로 정리해줘.
질문, 사용 데이터, 핵심 결과, 해석, 한계, 다음 행동의 순서로 작성해줘.
사실과 제안을 구분해줘.
```

## 어디까지 믿어야 할까요?

- 원본 행 수, 기간, 필터, 단위를 확인합니다.
- 중요한 계산은 다른 방법으로 다시 계산합니다.
- 빈값과 이상값 처리 방법을 기록합니다.
- 그래프 축이 왜곡되지 않았는지 확인합니다.
- 관찰된 패턴을 원인으로 단정하지 않습니다.
- 개인정보와 민감한 속성의 사용이 적절한지 검토합니다.

## 직접 해보기

### 과제

작은 표 데이터를 고릅니다. 구조 점검 → 질문 정의 → 계산 방법 확인 → 분석 → 한계 작성의 순서로 진행하고, 핵심 수치 하나를 직접 재계산하세요.

### 완료 체크

- [ ] 행과 열, 기간, 단위를 설명했다.
- [ ] 빈값·중복·이상값을 확인했다.
- [ ] 업무 질문과 계산 방법을 먼저 정했다.
- [ ] 핵심 계산을 직접 검증했다.
- [ ] 분석의 한계와 추가로 필요한 데이터를 적었다.

## 기억할 한 문장

> 데이터 분석은 멋진 차트를 만드는 일이 아니라, 데이터의 뜻과 품질을 확인한 뒤 업무 질문에 근거 있게 답하는 일입니다.
