# 정보 조사하기

> 상태: 초안

## 이번 장에서 할 일

조사 질문과 범위를 정하고, 최신 원출처를 확인해 사실·해석·남은 질문이 구분된 조사 결과를 만듭니다.

## 기억에 의존할지 검색할지 판단하기

다음 정보는 바뀔 가능성이 있으므로 웹 검색과 최신 출처 확인이 필요합니다.

- 법률, 정책, 규정, 지원 조건
- 가격, 제품 기능, 이용 가능 지역
- 일정, 인물, 조직의 현재 상태
- 시장 규모와 경제 지표
- 최근 사건과 뉴스

요청에 날짜 기준을 넣습니다.

```text
2026년 9월 현재 공개된 정보를 기준으로 조사해줘.
```

## 준비물

- 답하려는 질문
- 조사 기준일과 기간
- 지역 또는 대상 범위
- 포함할 것과 제외할 것
- 우선할 출처
- 최종 결과 형태와 독자

## 먼저 해보기

```text
2026년 9월 현재 국내 중소기업이 이용할 수 있는 공식 AI 교육 지원 프로그램을 조사해줘.
정부 기관과 운영 기관의 원출처를 우선 사용하고, 대상, 지원 내용, 신청 기한, 공식 링크를 표로 정리해줘.
현재 신청 가능한지 확인되지 않으면 “확인 필요”로 표시해줘.
```

## 조사 질문을 좁히기

“AI 시장을 조사해줘”는 범위가 너무 넓습니다. 다음을 구체화합니다.

- 어느 지역인가?
- 어느 기간인가?
- 어떤 대상이나 산업인가?
- 무엇을 결정하기 위한 조사인가?
- 어떤 종류의 자료를 포함할 것인가?

```text
조사 목적은 우리 팀이 다음 분기 교육 프로그램 하나를 고르는 것이야.
온라인 참여가 가능하고 비개발자 대상인 프로그램만 포함해줘.
```

## 출처의 우선순위 정하기

가능하면 주장에 가장 가까운 원출처를 먼저 봅니다.

```text
공식 기관의 공고와 운영 기관의 안내를 우선 사용해줘.
블로그나 재인용 기사만으로 확인되는 내용은 별도로 표시해줘.
```

출처마다 게시일과 업데이트 날짜, 실제 적용 시점을 확인합니다.

## 결과가 아쉽다면

### 주장과 출처 연결하기

```text
각 핵심 주장 바로 옆에 해당 내용을 직접 확인할 수 있는 출처 링크를 붙여줘.
하나의 링크로 확인되지 않는 주장은 나눠서 작성해줘.
```

### 상반된 정보 다루기

```text
출처가 서로 다르게 말하는 내용을 찾아 양쪽 주장을 출처와 함께 보여줘.
임의로 어느 쪽이 맞다고 결론 내리지 말고 차이가 생긴 이유와 추가 확인 방법을 알려줘.
```

### 최신성 점검하기

```text
출처의 게시일, 업데이트일, 정보가 적용되는 기간을 표에 추가해줘.
기준일보다 오래된 자료는 최신 자료로 대체하거나 이유를 설명해줘.
```

### 조사 한계 드러내기

```text
찾지 못한 정보, 접근하지 못한 자료, 사용한 가정, 추가 확인이 필요한 질문을 별도 항목으로 정리해줘.
```

## 뉴스와 사건을 조사할 때

게시일과 사건이 실제 발생한 날짜는 다를 수 있습니다. 여러 기사가 같은 보도자료를 반복한 것인지도 확인합니다.

```text
기사 게시일과 사건 발생일을 구분해줘.
가능하면 공식 발표나 원문 자료를 찾아 연결하고, 후속 보도로 사실이 바뀐 부분을 알려줘.
```

## 한 단계 더 해보기

조사 결과를 결정 문서로 바꿉니다.

```text
조사 결과를 팀장용 1쪽 결정 메모로 작성해줘.
질문, 확인된 사실, 선택지, 장단점, 추천, 남은 질문의 순서로 구성해줘.
사실과 네 해석을 구분하고 모든 핵심 주장에 출처를 붙여줘.
```

## 어디까지 믿어야 할까요?

- 링크가 실제 주장을 뒷받침하는지 직접 엽니다.
- 검색 결과 요약이 아니라 원문을 확인합니다.
- 게시일과 적용 기간을 확인합니다.
- 하나의 출처에만 의존하지 않습니다.
- 찾지 못했다는 사실이 존재하지 않는다는 뜻은 아닙니다.
- 법률, 의료, 재무 등 중요한 판단은 최신 공식 자료와 전문가 검토가 필요합니다.

## 직접 해보기

### 과제

실제 결정에 필요한 작은 조사 질문을 하나 고릅니다. 범위와 기준일을 정하고 원출처를 우선해 3개 이상의 출처를 비교하세요. 마지막에 확인된 사실, 해석, 남은 질문을 나눕니다.

### 완료 체크

- [ ] 조사 질문, 범위, 기준일을 정했다.
- [ ] 우선할 출처와 제외 기준을 말했다.
- [ ] 핵심 주장과 출처를 연결했다.
- [ ] 출처의 날짜와 실제 내용을 직접 확인했다.
- [ ] 사실, 해석, 미확인 정보를 구분했다.

## PART 3 최종 점검

- [ ] 업무 문제에 맞는 활용 유형을 고를 수 있다.
- [ ] 필요한 자료와 원하는 산출물을 설명할 수 있다.
- [ ] 첫 결과를 후속 요청으로 개선할 수 있다.
- [ ] 근거, 누락, 가정, 최신성을 검증할 수 있다.
- [ ] 결과를 다음 업무 산출물로 연결할 수 있다.

## 기억할 한 문장

> 좋은 조사는 답을 많이 모으는 일이 아니라, 범위를 정하고 원출처로 확인하며 사실과 해석의 경계를 남기는 일입니다.
