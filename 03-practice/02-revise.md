# 글 다듬기

> 상태: 초안

## 이번 장에서 할 일

원문의 의미와 사실은 유지하면서 더 명확하고 읽기 쉬운 글로 고칩니다.

## 새로 쓰기와 다듬기는 다릅니다

새로 쓰기는 빈 곳을 채우는 일이고, 다듬기는 이미 있는 내용에서 **보존할 것과 바꿀 것**을 구분하는 일입니다.

```text
아래 글을 읽기 쉽게 다듬어줘.
날짜, 수치, 고유명사와 핵심 입장은 바꾸지 마.
긴 문장을 나누고 중복 표현을 줄여줘.
```

## 준비물

- 원문
- 글의 독자와 사용처
- 반드시 유지할 문장·수치·용어
- 바꾸고 싶은 기준
- 바꾸면 안 되는 조직의 입장

## 먼저 해보기

연습용 원문:

```text
본 프로젝트의 일정과 관련하여 내부적으로 여러 가지 상황을 종합적으로 검토한 결과 기존에 안내드린 일정에서 이틀 정도 조정이 필요할 것으로 판단되어 관련 내용을 공유드리는 바입니다.
```

요청:

```text
아래 문장을 두 문장으로 나눠 명확하게 다듬어줘.
일정이 이틀 늦어진다는 의미는 유지하고, 책임을 회피하는 표현은 줄여줘.
```

## 결과가 아쉽다면

### 바뀐 이유 요청하기

```text
수정본 뒤에 중요한 변경 세 가지와 변경 이유를 알려줘.
의미가 달라질 가능성이 있는 부분은 따로 표시해줘.
```

### 독자 수준 맞추기

```text
비전공 신입사원이 읽는 글이야. 전문 용어는 쉬운 말로 바꾸고, 꼭 필요한 용어는 괄호로 설명해줘.
```

### 강도 조절하기

```text
사과의 뜻은 유지하되 지나치게 위축된 표현은 줄여줘.
바뀐 일정과 다음 행동이 더 잘 보이게 해줘.
```

### 부분만 고치기

```text
전체를 다시 쓰지 말고 첫 문단의 중복 표현만 줄여줘.
나머지 문장은 그대로 유지해줘.
```

## 원문과 수정본 비교하기

```text
원문과 수정본을 비교해 다음 표를 만들어줘.
열: 위치 / 원문 / 수정문 / 수정 이유 / 의미 변경 위험
날짜, 수치, 고유명사가 달라졌으면 가장 위에 경고해줘.
```

최종 판단은 사용자가 합니다. 매끄러워졌지만 중요한 단서가 사라질 수도 있습니다.

## 한 단계 더 해보기

한 원문을 두 독자용으로 바꿉니다.

```text
이 내용을 다음 두 버전으로 만들어줘.
1. 팀원용: 배경과 할 일을 포함한 6문장
2. 경영진용: 결론, 영향, 필요한 결정만 3문장
두 버전에서 사실은 동일하게 유지해줘.
```

## 어디까지 믿어야 할까요?

- 원문에 있던 조건과 예외가 빠지지 않았는지 확인합니다.
- 날짜, 수치, 이름이 바뀌지 않았는지 비교합니다.
- 원래 의도보다 강하거나 약해지지 않았는지 읽어봅니다.
- 계약, 정책, 법률 문구는 표현 변경이 의미를 바꿀 수 있으므로 전문 검토를 받습니다.

- [ ] 내 말투와 의도가 남아 있는지 직접 읽었다.
