# 번역하기

> 상태: 초안

## 이번 장에서 할 일

단어를 바꾸는 데서 그치지 않고, 독자·용도·말투에 맞는 번역문과 용어표를 만듭니다.

## 번역의 목적부터 정하세요

같은 문장도 계약서, 고객 이메일, 발표자료, 학습용 자료에서 번역 방식이 달라집니다.

| 목적 | 중요하게 볼 것 |
|---|---|
| 내용 파악 | 빠른 이해와 핵심 의미 |
| 외부 발송 | 자연스러운 표현과 관계에 맞는 말투 |
| 계약·정책 | 용어의 일관성과 의미 보존 |
| 발표자료 | 짧은 문장과 화면에서의 가독성 |
| 학습 | 원문 구조와 표현 설명 |

## 준비물

- 원문과 목표 언어
- 읽을 사람과 사용처
- 직역과 자연스러운 번역 중 우선순위
- 고정 번역어와 번역하지 않을 이름
- 유지할 표, 목록, 링크 형식

## 먼저 해보기

```text
아래 영어 이메일을 한국어로 번역해줘.
외부 고객에게 보내는 업무 메일이므로 정중하고 자연스럽게 써줘.
제품명과 사람 이름은 번역하지 말고 원문 표기를 유지해줘.
```

## 결과가 아쉽다면

### 직역과 자연스러운 번역 비교

```text
의미를 확인할 수 있는 직역과 실제 이메일에 쓸 자연스러운 번역을 나란히 보여줘.
차이가 큰 표현은 이유를 설명해줘.
```

### 용어 통일

```text
“workspace”는 “작업 공간”, “owner”는 “담당자”로 번역해줘.
문서 전체에서 같은 용어를 일관되게 사용하고 마지막에 용어표를 붙여줘.
```

### 애매한 문장 표시

```text
두 가지 의미로 해석될 수 있는 문장은 임의로 하나를 고르지 말고 가능한 해석과 확인 질문을 알려줘.
```

### 형식 유지

```text
제목, 번호, 글머리표, 링크 위치는 원문과 같게 유지해줘.
```

## 역번역으로 의미 확인하기

중요한 문장은 번역문을 다시 원래 언어로 번역해 의미 차이를 찾을 수 있습니다.

```text
한국어 번역문을 다시 영어로 역번역해줘.
원문과 의미가 달라진 부분을 표로 보여줘.
```

역번역도 완벽한 검증은 아닙니다. 중요한 문서는 해당 언어에 능숙한 사람이 확인합니다.

## 한 단계 더 해보기

한 번역을 여러 사용처에 맞춥니다.

```text
이 번역을 다음 두 버전으로 만들어줘.
1. 고객 이메일용: 정중한 전체 문장
2. 발표 슬라이드용: 핵심만 남긴 짧은 글머리표
두 버전의 사실과 수치는 동일하게 유지해줘.
```

## 어디까지 믿어야 할까요?

- 숫자, 단위, 날짜, 부정 표현이 달라지지 않았는지 확인합니다.
- 문화적 표현과 존칭이 독자에게 적절한지 검토합니다.
- 계약, 의료, 법률, 안전 문서는 전문 번역과 전문가 검토가 필요합니다.
- 기밀 문서는 조직의 번역 도구 사용 정책을 먼저 확인합니다.

## 직접 해보기

### 과제

짧은 업무 문단을 골라 직역과 자연스러운 번역을 만듭니다. 용어표를 만들고 의미가 크게 달라진 표현 세 개를 비교하세요.

### 완료 체크

- [ ] 독자와 사용처를 설명했다.
- [ ] 고정 용어와 유지할 형식을 지정했다.
- [ ] 애매한 표현을 확인했다.
- [ ] 숫자·날짜·부정 표현을 원문과 대조했다.

## 기억할 한 문장

> 좋은 번역은 단어를 바꾸는 일이 아니라, 원문의 의미를 새 독자와 사용처에 맞게 정확히 전달하는 일입니다.
