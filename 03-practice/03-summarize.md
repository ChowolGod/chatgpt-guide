# 긴 내용 요약하기

> 상태: 초안

## 이번 장에서 할 일

긴 자료에서 목적에 필요한 내용을 골라 핵심 요약과 후속 행동 목록을 만듭니다.

## 요약은 단순히 줄이는 일이 아닙니다

같은 자료도 왜 읽는지에 따라 남겨야 할 내용이 다릅니다.

- 경영진은 결론과 필요한 결정을 원할 수 있습니다.
- 실무자는 담당자와 마감일을 찾아야 합니다.
- 처음 배우는 사람은 개념과 예시가 필요합니다.
- 검토자는 조건, 예외, 위험을 놓치면 안 됩니다.

따라서 “요약해줘” 다음에 **누가 무엇을 위해 읽는지**를 붙입니다.

## 준비물

- 요약할 원문 또는 파일
- 읽을 사람
- 요약을 사용하는 목적
- 반드시 남길 항목
- 원문 위치를 표시하는 방법

## 먼저 해보기

```text
아래 회의 메모를 회의에 참석하지 못한 팀원을 위해 요약해줘.
결정사항, 아직 결정되지 않은 사항, 담당자, 마감일을 구분해줘.
메모에 없는 내용은 추측하지 말고 “확인 필요”로 표시해줘.
```

## 결과가 아쉽다면

### 길이 정하기

```text
맨 위에 3줄 요약을 쓰고, 그 아래에 상세 내용을 붙여줘.
```

### 근거 위치 남기기

```text
각 핵심 항목이 나온 원문 문단이나 페이지를 표시해줘.
원문에서 직접 확인되지 않는 해석은 별도로 구분해줘.
```

### 누락 점검하기

```text
요약 때문에 빠진 조건, 예외, 반대 의견, 미결정 사항이 있는지 원문과 다시 대조해줘.
```

### 사실과 해석 분리하기

```text
원문에 명시된 사실과 네가 해석한 내용을 서로 다른 항목으로 나눠줘.
```

## 목적별 요청 예시

### 결정을 위한 요약

```text
이 보고서를 부서장이 3분 안에 읽고 A안과 B안 중 하나를 결정할 수 있게 요약해줘.
결론, 선택지별 장단점, 비용, 위험, 추가로 필요한 정보를 포함해줘.
```

### 행동을 위한 요약

```text
이 안내문에서 내가 해야 할 일, 제출할 자료, 기한, 문의처만 체크리스트로 정리해줘.
```

### 학습을 위한 요약

```text
이 자료를 처음 접하는 사람이 이해하도록 핵심 개념 5개와 개념별 예시를 정리해줘.
마지막에 이해 확인 문제 3개를 만들어줘.
```

## 한 단계 더 해보기

요약을 다음 산출물로 연결합니다.

```text
이 회의 요약을 바탕으로 담당자별 Action Item 표를 만들고, 참석자에게 보낼 후속 이메일 초안도 작성해줘.
두 결과의 담당자와 마감일이 서로 같은지 확인해줘.
```

## 어디까지 믿어야 할까요?

- 요약은 필연적으로 정보를 버리므로 원문의 조건과 예외를 대조합니다.
- 숫자, 이름, 날짜, 인용은 원문과 직접 확인합니다.
- 원문에 없는 결론이나 원인을 추가하지 않았는지 봅니다.
- 파일의 표, 각주, 부록, 이미지가 분석 대상에 포함됐는지 확인합니다.
