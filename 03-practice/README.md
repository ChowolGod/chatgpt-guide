# PART 3. 필요한 일을 직접 해보기

자주 만나는 업무 문제를 하나씩 해결하며 공통 활용 원리를 익힙니다.

## 이 Part를 사용하는 방법

처음부터 모든 장을 순서대로 할 필요는 없습니다. 지금 해야 하는 일과 가장 가까운 장을 골라 다음 순서로 실습하세요.

```text
업무 문제 고르기
→ 준비할 자료 확인하기
→ 첫 요청 실행하기
→ 부족한 조건 추가하기
→ 근거와 누락 검증하기
→ 실제 산출물로 사용하기
```

처음에는 결과를 직접 확인하기 쉽고, 틀려도 영향이 작은 업무부터 시작하는 것이 좋습니다.
