# 파일 읽고 분석하기

> 상태: 초안

## 이번 장에서 할 일

문서·표·발표자료·PDF 같은 파일을 제공하고, 읽을 범위와 원하는 결과를 지정해 요약·추출·비교합니다.

## 파일을 올리는 것만으로는 요청이 되지 않습니다

파일과 함께 다음을 알려주세요.

- 무엇을 알고 싶은가?
- 어느 부분을 봐야 하는가?
- 어떤 결과를 만들어야 하는가?
- 근거 위치를 어떻게 표시할 것인가?
- 읽지 못한 부분은 어떻게 처리할 것인가?

## 준비물

- 분석할 정확한 버전의 파일
- 파일의 종류와 목적
- 확인할 질문 또는 항목
- 필요한 결과 형태
- 민감정보 제거 여부

## 먼저 해보기

```text
첨부한 보고서를 읽고 부서장이 확인해야 할 핵심 결론, 근거 수치, 주요 위험, 필요한 결정을 정리해줘.
각 항목에 출처 페이지를 표시하고, 파일에서 확인되지 않는 내용은 추측하지 마.
```

## 파일 종류별 요청

### 문서와 PDF

```text
이 문서에서 계약 기간, 비용, 해지 조건, 책임 범위를 찾아 표로 정리해줘.
각 내용이 나온 조항이나 페이지를 표시해줘.
```

### 스프레드시트

```text
이 파일의 시트 이름, 각 표의 행과 열 의미, 기간, 단위를 먼저 설명해줘.
분석을 시작하기 전에 비어 있거나 해석이 애매한 열을 알려줘.
```

### 발표자료

```text
이 발표자료의 슬라이드별 핵심 메시지를 한 문장씩 정리해줘.
주장에 근거가 부족한 슬라이드와 서로 내용이 충돌하는 슬라이드를 표시해줘.
```

### 여러 파일 비교

```text
세 파일의 버전 날짜를 먼저 확인하고, 정책 내용이 달라진 부분을 비교해줘.
최신 파일을 임의로 정하지 말고 판단 근거를 보여줘.
```

## 결과가 아쉽다면

### 범위 좁히기

```text
전체 요약 대신 3장 예산 부분과 부록의 비용표만 분석해줘.
```

### 근거 추적하기

```text
각 핵심 주장 옆에 파일명과 페이지 또는 표 위치를 붙여줘.
```

### 누락 확인하기

```text
읽지 못한 페이지, 이미지, 표, 주석이 있는지 알려줘.
분석에서 제외된 부분도 목록으로 남겨줘.
```

## 한 단계 더 해보기

파일을 새 산출물의 자료로 사용합니다.

```text
이 보고서의 확인된 내용만 사용해 1쪽 경영진 요약을 작성해줘.
사실과 네 분석을 구분하고 모든 수치에 원본 파일과 페이지를 표시해줘.
```

## 어디까지 믿어야 할까요?

- 파일명과 버전이 맞는지 확인합니다.
- 파일 전체를 읽었는지, 표·각주·이미지가 누락됐는지 확인합니다.
- 수치와 인용을 원본 위치에서 직접 대조합니다.
- 스캔 품질이 낮거나 복잡한 표는 잘못 읽을 수 있습니다.
- 개인정보, 고객정보, 기밀자료는 조직 정책에 따라 다룹니다.

## 직접 해보기

### 과제

민감정보가 없는 파일 하나를 고릅니다. 먼저 파일 구조와 읽지 못한 부분을 확인한 뒤, 목적별 질문 세 개를 하고 근거 위치가 있는 요약을 만드세요.

### 완료 체크

- [ ] 올바른 파일과 버전을 사용했다.
- [ ] 분석 목적과 범위를 말했다.
- [ ] 근거 위치를 요청했다.
- [ ] 누락되거나 읽지 못한 부분을 확인했다.
- [ ] 중요한 내용은 원본에서 직접 대조했다.
