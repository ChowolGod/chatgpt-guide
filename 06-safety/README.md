# PART 6. 안전하게 사용하기

ChatGPT의 결과를 무조건 믿거나 무조건 버리지 않고, 일의 위험에 맞는 검증·보안·승인 절차를 만듭니다.

## 이 Part를 사용하는 방법

결과를 받은 뒤 다음 순서로 확인하세요.

```text
틀렸을 때의 영향 판단
→ 사실·해석·제안 구분
→ 중요한 근거와 출처 대조
→ 입력·출력에 민감정보가 없는지 확인
→ 필요한 사람의 검토와 승인
→ 사용한 자료와 결정 기록
```

모든 답변을 같은 강도로 검증할 필요는 없습니다. 회식 아이디어와 계약 해지 통지문은 틀렸을 때의 영향이 다릅니다. 검토에 쓸 시간과 사람도 그 영향에 맞춰 정합니다.

## 안전 사용의 기본 원칙

- 자연스러운 문장과 정확한 내용은 별개입니다.
- 확인할 수 없는 부분은 추측보다 빈칸이 낫습니다.
- 중요한 결정의 책임은 도구가 아니라 사람과 조직에 있습니다.
- 필요한 최소한의 정보와 권한만 사용합니다.
- 외부 발송·게시·결제·삭제 전에 사람이 최종 확인합니다.

**Part 완료 기준:** 결과가 틀렸을 때의 위험을 평가하고, 주장별 검증·정보 보호·전문가 검토·승인 절차를 정할 수 있다.
