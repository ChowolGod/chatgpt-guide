# 출처 확인하기

> 상태: 초안

## 이번 장에서 할 일

출처 링크의 존재만 확인하지 않고, 발행 주체·최신성·원문과 주장의 일치를 검토합니다.

## 출처가 있다고 검증된 것은 아닙니다

링크가 있어도 다음 문제가 있을 수 있습니다.

- 페이지가 존재하지 않거나 열리지 않는다.
- 원문이 아니라 원문을 다시 요약한 글이다.
- 오래된 자료라 현재 상황과 다르다.
- 출처가 관련 주제를 다루지만 해당 주장은 뒷받침하지 않는다.
- 제한된 조사 결과를 모든 사람에게 적용한다.

## 주장 하나씩 연결하세요

문서 끝에 출처 목록만 모아두면 어떤 출처가 어떤 주장을 뒷받침하는지 알기 어렵습니다.

```text
주요 주장마다 바로 뒤에 출처 링크를 붙여줘.
각 주장에 발행 주체, 발행 또는 수정 날짜,
근거가 있는 원문 위치를 함께 적어줘.
출처가 없는 주장은 [근거 확인 필요]라고 표시해줘.
```

## 다섯 가지를 대조하세요

| 확인 항목 | 질문 |
|---|---|
| 존재 | 링크가 실제로 열리는가? |
| 발행 주체 | 누가 어떤 책임으로 만들었는가? |
| 원출처 | 공식 발표·원문 연구·원본 데이터인가? |
| 최신성 | 질문의 기준 시점에 맞는가? |
| 일치 | 원문이 답변의 주장을 실제로 뒷받침하는가? |

## 원출처를 우선하세요

- 법과 정책: 법령 원문과 담당 기관
- 회사 기능과 가격: 회사 공식 안내와 가격표
- 통계: 통계를 직접 작성한 기관과 원자료
- 연구: 원문 논문과 연구기관
- 조직 내부 정보: 승인된 최신 사내 문서와 담당 부서

해설 자료는 이해를 돕지만 최종 확인은 가능한 한 원출처에서 합니다.

## 출처 확인표를 만드세요

| 주장 | 출처 | 날짜 | 원문 위치 | 판단 |
|---|---|---|---|---|
| 서비스 가격은 월 2만 원이다 | 공식 가격표 | 확인일 기재 | 요금제 표 | 일치/불일치 |
| 이용자가 증가하고 있다 | 통계 보고서 | 조사 기간 기재 | 3쪽 그래프 | 범위 제한 필요 |

판단에는 `일치`, `일부 일치`, `불일치`, `확인 불가`처럼 정해진 표시를 사용하면 좋습니다.

## 직접 인용은 앞뒤를 읽으세요

한 문장만 떼면 원래 의미와 달라질 수 있습니다. 인용문 앞뒤 문단, 표의 주석, 조사 한계, 예외 조건을 함께 확인합니다. 인용 부호 안의 문장은 원문과 글자까지 대조하세요.

## 여러 출처가 같은 말을 해도 독립적인지 보세요

기사 세 개가 같은 보도자료 하나를 옮겼다면 독립된 근거 세 개가 아닙니다. 각 글이 어디에서 정보를 가져왔는지 거슬러 올라가세요.

```text
이 출처들이 서로 독립적인지 확인해줘.
같은 원자료를 인용한 자료는 묶고,
가장 가까운 원출처를 표시해줘.
```

## 찾지 못한 근거를 만들어내지 않게 하세요

```text
정확한 출처를 확인할 수 없다면 비슷한 링크를 대신 붙이지 마.
무엇을 검색했고 무엇을 찾지 못했는지 적고,
해당 주장은 결과에서 제외하거나 확인 필요로 남겨줘.
```

## 어디까지 믿어야 할까요?

ChatGPT가 제시한 출처표는 검토 목록입니다. 중요한 링크는 직접 열고, 원문에서 근거 위치를 찾아 문맥과 날짜를 확인해야 합니다. 접근할 수 없는 유료 자료나 내부 문서는 확인됐다고 처리하지 않습니다.

## 직접 해보기

### 과제

업무 문서의 핵심 주장 하나를 고릅니다. 출처 링크, 발행 주체, 날짜, 원문 위치, 실제 근거 내용을 대조하고 판정을 기록하세요.

### 완료 체크

- [ ] 출처 링크를 직접 열었다.
- [ ] 발행 주체와 원출처 여부를 확인했다.
- [ ] 발행일·수정일·조사 기간을 구분했다.
- [ ] 원문의 앞뒤 문맥과 주석을 읽었다.
- [ ] 여러 출처가 독립적인지 확인했다.
- [ ] 확인하지 못한 주장을 표시하거나 제외했다.

## 기억할 한 문장

**출처 확인은 링크를 세는 일이 아니라 원문이 바로 그 주장을 뒷받침하는지 대조하는 일입니다.**
