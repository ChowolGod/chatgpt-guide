# ChatGPT DIY 가이드

비전공자·비개발자가 ChatGPT를 처음 접한 뒤, 자신의 업무에 맞는 활용법을 스스로 설계할 수 있도록 돕는 실전형 입문 가이드입니다.

## 이 가이드의 철학

> 무엇을 할 수 있는가 → 언제 쓰는가 → 어떻게 요청하는가 → 어떻게 더 잘 쓰는가 → 어디까지 믿어야 하는가 → 실제 업무에 어떻게 연결하는가

좋은 프롬프트를 외우는 데서 끝내지 않습니다. 작은 요청으로 시작하고, 결과를 확인하고, 조건을 더하고, 검증하고, 실제 산출물로 완성하는 과정을 반복해서 익힙니다.

## 대상 독자

- ChatGPT를 처음 사용하거나 검색창처럼만 사용해 본 사람
- AI·개발 용어에 익숙하지 않은 비전공자·비개발자
- 글쓰기, 요약, 조사, 자료 정리, 분석 등 실제 업무에 활용하려는 사람

## 완독 후 할 수 있는 것

- 원하는 일을 자연어로 설명하고 필요한 맥락과 조건을 덧붙일 수 있다.
- 첫 답변을 평가하고 후속 대화로 개선할 수 있다.
- 자료를 요약·정리·변환하고 업무 산출물의 초안을 만들 수 있다.
- 파일, 데이터, 웹 검색 등 필요한 수단을 상황에 맞게 선택할 수 있다.
- 오류·보안·개인정보 위험을 판단하고 결과를 검증할 수 있다.
- 반복 업무를 발견해 자신만의 ChatGPT 작업 흐름과 요청 템플릿을 만들 수 있다.
