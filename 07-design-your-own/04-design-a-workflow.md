# 하나의 업무 흐름을 ChatGPT와 함께 설계하기

> 상태: 초안 전

## 최종 DIY 프로젝트

1. 시작 자료와 최종 산출물을 정의합니다.
2. 업무를 작은 단계로 나눕니다.
3. ChatGPT가 할 일과 사람이 할 일을 구분합니다.
4. 단계별 요청과 결과 형태를 정합니다.
5. 검증·승인·보안 지점을 표시합니다.
6. 실제로 한 번 실행하고 문제를 기록합니다.
7. 템플릿과 절차를 수정해 두 번째로 실행합니다.

## 최종 산출물

- 업무 흐름 한 장 요약
- 단계별 요청 템플릿
- 입력 자료 체크리스트
- 결과 검증 체크리스트
- 실행 후 회고와 다음 개선점

## 완료 체크

- [ ] 실제 내 업무에 적용했다.
- [ ] ChatGPT가 할 일과 사람이 판단할 일을 구분했다.
- [ ] 정보가 부족할 때의 처리 방법을 정했다.
- [ ] 오류·개인정보·승인 위험을 검토했다.
- [ ] 다른 날에도 다시 쓸 수 있는 형태로 남겼다.
