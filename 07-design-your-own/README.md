# PART 7. 나만의 활용법 만들기

지금까지 배운 원리를 자신의 실제 업무 하나에 적용해, 다음번에도 사용할 수 있는 작업 흐름으로 완성합니다.

## 이 Part의 결과물

마지막 장까지 마치면 다음 다섯 가지가 남습니다.

1. 먼저 적용할 업무 한 가지
2. 복사해서 다시 쓸 요청 템플릿
3. 첫 버전과 개선 버전의 비교 기록
4. 사람과 ChatGPT의 역할이 표시된 업무 흐름
5. 입력·검증·승인·회고 체크리스트

## 진행 순서

```text
후보 업무 모으기
→ 작고 안전한 첫 업무 고르기
→ 요청 템플릿 만들기
→ 실제 자료로 실행하기
→ 결과를 기준표로 평가하기
→ 한 요소씩 개선하기
→ 전체 업무 흐름으로 연결하기
→ 다른 날 다시 실행하기
```

완벽한 자동화를 만들 필요는 없습니다. 일주일에 20분을 줄이고 누락 하나를 막는 흐름도 충분히 좋은 첫 결과입니다.

## 시작 전 약속

- 처음에는 낮은 위험의 작은 업무를 고릅니다.
- 실제 결과를 보고 고치며, 머릿속으로만 완성하지 않습니다.
- 날짜·수치·이름·출처는 사람이 확인합니다.
- 외부 발송과 중요한 결정은 자동으로 맡기지 않습니다.
- 절약한 시간뿐 아니라 결과 품질과 위험도 함께 기록합니다.

**Part 완료 기준:** 실제 업무 하나에 적용할 요청 템플릿과 작업 흐름을 만들고, 두 번 이상 시험해 검증 기준과 다음 개선점을 남긴다.
