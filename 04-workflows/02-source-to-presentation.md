# 자료에서 발표자료까지

> 상태: 초안

## 이번 장에서 할 일

여러 원자료를 목적별로 요약하고, 근거가 추적되는 보고서와 발표자료 구성으로 연결합니다.

```text
원자료
→ 자료 목록과 범위 확인
→ 목적별 요약
→ 주장-근거 표
→ 보고서
→ 슬라이드 구성
→ 산출물 간 일치 검토
```

## 완성할 산출물

- 사용한 자료와 제외한 자료 목록
- 핵심 주장과 근거 위치 표
- 1쪽 보고서
- 슬라이드별 구성안
- 보고서와 발표자료의 불일치 점검표

## 예시 상황

분기 고객 만족도 조사 결과, 고객 인터뷰 메모, 지난 분기 보고서를 바탕으로 경영진에게 개선 우선순위를 제안해야 합니다.

## 준비물

- 정확한 버전의 원자료
- 자료별 작성일과 목적
- 발표 청중과 필요한 결정
- 보고서 분량과 발표 시간
- 반드시 사용하거나 제외할 자료
- 검토를 맡을 내용 담당자

## 1단계: 자료 지도를 만들기

```text
첨부한 자료를 바로 요약하지 말고 먼저 자료 지도를 만들어줘.
파일명 / 작성일 / 자료 유형 / 다루는 기간 / 핵심 내용 / 제한사항의 표로 정리해줘.
읽지 못한 파일, 표, 이미지, 페이지가 있으면 알려줘.
서로 다른 버전으로 보이는 자료도 표시해줘.
```

오래된 보고서와 최신 조사 결과가 섞였다면 어느 시점의 사실인지 구분해야 합니다.

## 사람의 검토 1: 사용할 자료 확정하기

- 최신 버전이 맞는가?
- 조사 기간과 대상이 같은가?
- 비교에 필요한 정의와 단위가 일치하는가?
- 개인정보가 제거됐는가?
- 참고만 할 자료와 근거로 쓸 자료가 구분됐는가?

## 2단계: 목적에 맞게 요약하기

```text
목적은 경영진이 다음 분기의 고객 경험 개선 우선순위 2개를 결정하게 하는 것이야.
확정한 자료에서 다음만 요약해줘.
- 가장 큰 고객 불편 3개
- 지난 분기와 달라진 점
- 불편별 근거 수치와 대표 의견
- 자료만으로 확인할 수 없는 내용
모든 항목에 파일명과 페이지 또는 표 위치를 표시해줘.
```

## 3단계: 주장과 근거 연결하기

```text
요약을 주장-근거 표로 바꿔줘.
열은 핵심 주장 / 근거 수치 / 정성 근거 / 출처 위치 / 반대 근거 / 확신 수준 / 추가 확인으로 해줘.
하나의 근거로 확인되지 않는 주장은 나누고, 자료에 없는 주장은 삭제해줘.
```

이 표가 보고서와 발표자료의 공통 기준이 됩니다.

## 사람의 검토 2: 해석 승인하기

- 표본 수와 조사 방식이 충분한가?
- 고객 한 명의 의견을 전체 의견처럼 확대하지 않았는가?
- 수치와 인터뷰가 같은 현상을 말하는가?
- 상반된 근거가 빠지지 않았는가?
- 관찰된 관계를 원인으로 단정하지 않았는가?

## 4단계: 1쪽 보고서 만들기

```text
승인한 주장-근거 표를 바탕으로 경영진용 1쪽 보고서를 작성해줘.

순서:
1. 필요한 결정
2. 핵심 결론 3줄
3. 근거가 있는 주요 발견
4. 개선 우선순위 2개와 이유
5. 위험과 한계
6. 다음 행동

사실과 분석을 구분하고, 모든 수치에 출처를 붙여줘.
```

## 5단계: 슬라이드 구성으로 바꾸기

```text
승인한 보고서를 7분 발표용 6장 구성으로 바꿔줘.
각 슬라이드에 다음을 적어줘.
- 결론형 제목 한 문장
- 전달할 핵심 내용
- 사용할 근거와 출처
- 추천 시각화
- 발표자 메모
- 확인할 사실
보고서에 없는 새 주장은 추가하지 마.
```

## 6단계: 보고서와 발표자료 대조하기

```text
보고서와 슬라이드 구성안을 대조해줘.
수치, 기간, 용어, 우선순위, 추천안, 위험 설명이 서로 다른 부분을 표로 보여줘.
슬라이드에서 지나치게 단순화되어 의미가 바뀐 부분도 찾아줘.
```

## 실제 파일을 만들었다면

파일 생성이 끝났다고 검토가 끝난 것은 아닙니다. 모든 페이지와 슬라이드를 직접 엽니다.

- 제목과 본문이 잘리지 않았는가?
- 표와 차트의 글자를 읽을 수 있는가?
- 출처가 보이는가?
- 슬라이드 순서가 자연스러운가?
- 보고서와 발표자료의 숫자가 같은가?

## 최종 확인 체크리스트

- [ ] 사용한 자료와 제외한 자료가 기록됐다.
- [ ] 주장마다 원자료 위치가 있다.
- [ ] 사실, 해석, 추천이 구분됐다.
- [ ] 보고서와 슬라이드의 수치·용어·추천이 일치한다.
- [ ] 생성된 모든 페이지와 슬라이드를 직접 확인했다.
- [ ] 경영진에게 필요한 결정이 앞에 나온다.

```text
자료 범위, 해석, 수치, 실제 파일은 누가 확인하는가?
```
