# 회의 메모에서 후속 이메일까지

> 상태: 초안

## 이번 장에서 할 일

뒤섞인 회의 메모를 회의록, Action Item 표, 참석자 후속 이메일로 차례로 바꿉니다.

```text
회의 메모
→ 사실과 미결정 사항 구분
→ 회의록
→ Action Item 표
→ 사람의 확인
→ 후속 이메일 초안
```

## 완성할 산출물

- 참석하지 않은 사람도 이해할 수 있는 회의록
- 담당자와 마감일이 보이는 Action Item 표
- 결정사항과 다음 행동을 알리는 후속 이메일 초안
- 확인이 필요한 항목 목록

## 준비물

- 원본 회의 메모 또는 녹취
- 회의명, 일시, 참석자
- 회의 목적과 예정된 안건
- 개인정보·민감정보 처리 기준
- 최종 확인을 맡을 회의 참석자

녹취나 메모에 고객정보와 기밀이 포함됐다면 조직 정책을 먼저 확인합니다.

## 연습용 회의 메모

```text
프로젝트 중간 점검 / 10월 8일 14:00
참석: 고객사 김담당, 우리 팀 이기획·박디자인·최개발

- 고객 검토 의견은 금요일까지 받기로 했던 것 같은데 고객사는 월요일 오전 가능하다고 함
- 새 화면은 3종이 아니라 핵심 2종 먼저. 나머지 1종은 다음 배포로?
- 10/22 배포 목표. 최개발: 가능하지만 고객 확인 늦으면 영향 있음
- 박디자인이 수정 시안 준비, 언제까지인지는 말 안 나온 듯
- 다음 회의 10/15 오후 2시, 장소/링크 미정
- 예산 추가는 없음
- 김담당이 내부 결재 라인 확인
```

## 1단계: 바로 회의록을 쓰지 말고 내용 구분하기

```text
아래 회의 메모를 먼저 분석해줘.
확정된 사실, 결정사항, 제안, 미결정 사항, 확인이 필요한 정보를 구분해줘.
담당자나 날짜가 분명하지 않으면 추측하지 말고 “확인 필요”로 표시해줘.

[회의 메모 붙여넣기]
```

이 단계에서 “나머지 1종은 다음 배포”가 실제 결정인지 제안인지 확인해야 합니다.

## 사람의 검토 1: 사실 확정하기

원본 메모와 대조해 다음을 확인합니다.

- 화면 2종 우선 제작이 확정됐는가?
- 고객 검토 기한은 월요일 몇 시인가?
- 수정 시안 담당자와 마감일은 무엇인가?
- 10월 22일은 목표일인가 확정일인가?
- 다음 회의 장소와 링크는 누가 정하는가?

확인할 수 없다면 빈칸을 지우지 말고 미결정 사항으로 남깁니다.

## 2단계: 팀 공유용 회의록 만들기

```text
확정된 내용만 사용해 팀 공유용 회의록을 작성해줘.

순서:
1. 회의 정보
2. 3줄 핵심 요약
3. 결정사항
4. 논의 내용
5. Action Item
6. 미결정·확인 필요 사항
7. 다음 회의

원문에 없는 내용은 추가하지 말고, 목표와 확정을 구분해줘.
```

회의록의 목적은 모든 말을 기록하는 것이 아니라, 무엇을 결정했고 다음에 누가 무엇을 해야 하는지 남기는 것입니다.

## 3단계: Action Item 표 만들기

```text
회의록에서 실제 행동이 필요한 항목만 뽑아 표로 만들어줘.
열은 할 일 / 담당자 / 마감일 / 완료 조건 / 근거 / 상태로 해줘.
담당자나 마감일이 없으면 임의로 채우지 말고 “확인 필요”로 표시해줘.
```

예상 형태:

| 할 일 | 담당자 | 마감일 | 완료 조건 | 상태 |
|---|---|---|---|---|
| 수정 시안 준비 | 박디자인 | 확인 필요 | 고객 검토 가능한 시안 공유 | 확인 필요 |
| 내부 결재 라인 확인 | 김담당 | 확인 필요 | 결재 담당자와 소요 기간 회신 | 확인 필요 |

## 사람의 검토 2: 책임과 날짜 확인하기

Action Item은 사람에게 실제 책임을 부여합니다. 참석자가 다음을 확인한 뒤 확정합니다.

- 담당자가 회의에서 실제로 동의했는가?
- 마감일의 날짜와 시간대가 분명한가?
- 완료 조건을 모두 같은 의미로 이해하는가?
- 다른 일정과 충돌하지 않는가?

ChatGPT가 제안한 담당자를 확정된 담당자처럼 배포하면 안 됩니다.

## 4단계: 후속 이메일 초안 만들기

```text
확인된 회의록과 Action Item을 바탕으로 참석자 후속 이메일 초안을 작성해줘.

목적:
- 결정사항 공유
- 담당자와 마감일 확인
- 미결정 사항에 대한 답변 요청

형식:
- 제목
- 감사 인사 1문장
- 결정사항 글머리표
- Action Item 표
- 확인이 필요한 질문
- 다음 회의 안내

초안만 만들고 실제로 발송하지 마.
```

## 5단계: 세 산출물의 일치 확인하기

```text
원본 메모, 회의록, Action Item 표, 후속 이메일을 서로 대조해줘.
다음 불일치를 찾아 표로 보여줘.
- 날짜와 시간
- 결정 여부
- 담당자
- 마감일
- 다음 회의 정보
문제가 있으면 원본 메모를 기준으로 수정안을 제안하되, 애매한 내용은 확정하지 마.
```

## 최종 확인 체크리스트

- [ ] 회의명, 일시, 참석자가 정확하다.
- [ ] 결정사항과 제안·미결정 사항이 구분됐다.
- [ ] 모든 Action Item에 담당자와 마감일이 있거나 `확인 필요` 표시가 있다.
- [ ] 회의록과 이메일의 날짜·담당자가 일치한다.
- [ ] 고객정보와 기밀이 불필요하게 포함되지 않았다.
- [ ] 참석자가 검토한 뒤 이메일을 발송한다.

## 내 업무에 적용하기

내 회의 유형에 맞춰 고정할 항목을 정합니다.

```text
[입력]
회의 정보 + 원본 메모

[중간 산출물]
사실/결정/제안/미결정 분류

[최종 산출물]
회의록 + Action Item + 후속 이메일 초안

[사람의 검토]
결정 여부 + 담당자 + 마감일 + 외부 발송
```

## 기억할 한 문장

> 회의 메모를 바로 이메일로 바꾸지 말고, 사실과 결정을 확인한 뒤 회의록과 Action Item을 거쳐 연결하세요.
