# PART 4. 업무 하나를 처음부터 끝까지 처리하기

한 번의 질문이 아니라 여러 산출물이 이어지는 업무 흐름을 설계합니다.

## 이 Part를 사용하는 방법

각 장은 같은 원칙을 사용합니다.

```text
시작 자료 확인
→ 검토 가능한 작은 단계로 나누기
→ 중간 산출물마다 사람이 확인하기
→ 최종 산출물 만들기
→ 산출물 사이의 사실과 수치 대조하기
```

중간 산출물은 일을 늦추는 문서가 아닙니다. 잘못된 방향을 일찍 발견하고, 최종 결과가 어디에서 나왔는지 확인하게 해주는 안전장치입니다.
