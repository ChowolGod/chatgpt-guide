# 조건을 붙이기

> 상태: 초안

## 이번 장에서 할 일

결과가 실제 업무에서 쓸 수 있도록 **반드시 지킬 조건, 피할 것, 우선순위**를 정합니다.

## 조건은 결과의 울타리입니다

목적과 맥락이 방향을 알려준다면, 조건은 결과가 벗어나면 안 되는 범위를 알려줍니다.

앞 장의 회의 안내 요청에 조건을 더해보겠습니다.

```text
프로젝트에 참여하는 외부 고객에게 보낼 중간 점검 회의 안내 이메일을 작성해줘.
지난 회의에서 일정 지연 가능성을 공유했고, 이번 회의에서는 변경 일정을 확정해야 해.

다음 조건을 지켜줘.
- 본문은 7문장 이내
- 회의 목적, 날짜, 시간, 준비할 내용을 반드시 포함
- 지연 원인을 확정적으로 단정하지 않기
- 장소와 링크는 정해지지 않았으니 임의로 만들지 않기
- 10월 10일까지 참석 가능 여부 회신 요청하기
```

## 자주 쓰는 조건의 종류

### 길이와 범위

- 5문장 이내
- 한 페이지 분량
- 핵심 세 가지만
- 지난 분기 데이터만
- 한국 시장만

### 반드시 포함할 것

- 결정사항과 다음 행동
- 담당자와 마감일
- 근거가 된 수치
- 독자가 답해야 할 질문

### 제외하거나 피할 것

- 전문 용어 사용하지 않기
- 과장된 표현 제외하기
- 자료에 없는 내용 추측하지 않기
- 개인을 식별할 수 있는 정보 제외하기

### 유지할 것

- 승인된 날짜와 예산은 바꾸지 않기
- 제품명은 원문 표기 유지하기
- 인용문은 수정하지 않기
- 원문의 핵심 입장 유지하기

### 행동 경계

- 초안만 만들고 발송하지 않기
- 파일을 바꾸기 전에 변경안을 먼저 보여주기
- 정보가 충돌하면 임의로 선택하지 말고 질문하기
- 외부에 공개하기 전에 승인을 요청하기

행동 경계는 다른 사람이나 시스템에 영향을 줄 수 있는 작업에서 특히 중요합니다.

## 중요한 조건부터 적으세요

조건이 많으면 서로 충돌하거나 핵심이 묻힐 수 있습니다. 결과를 망칠 수 있는 조건부터 두세 개를 고릅니다.

```text
가장 중요한 조건:
1. 승인된 날짜와 예산 수치는 바꾸지 않는다.
2. 자료에 없는 정보는 추측하지 않고 “확인 필요”로 표시한다.
3. 외부 발송용 초안만 만들고 실제로 보내지는 않는다.
```

말투나 문장 길이처럼 나중에 쉽게 고칠 수 있는 항목은 후속 요청으로 조정해도 됩니다.

## 모호한 조건을 확인 가능한 기준으로 바꾸기

| 모호한 표현 | 확인 가능한 조건 |
|---|---|
| 짧게 써줘 | 본문을 7문장 이내로 써줘 |
| 전문적으로 써줘 | 결론을 먼저 쓰고 근거 수치 3개를 표로 보여줘 |
| 보기 좋게 정리해줘 | 제목, 핵심 요약, 할 일 표의 순서로 구성해줘 |
| 자세히 설명해줘 | 개념, 예시, 주의점, 확인 문제를 포함해줘 |
| 최신 자료를 써줘 | 2026년 9월 현재 자료를 검색하고 출처 날짜를 표시해줘 |

결과를 보고 지켰는지 판단할 수 있어야 좋은 조건입니다.

## 우선순위를 알려주기

조건이 충돌할 수 있다면 무엇이 더 중요한지 말합니다.

```text
간결함보다 결정사항의 누락 방지가 더 중요해.
필요하다면 문장 수 제한을 넘겨도 되지만, 넘긴 이유를 알려줘.
```

```text
창의성보다 사실 정확성을 우선해줘.
자료에 근거하지 않은 제안은 별도 항목으로 구분해줘.
```

## 조건을 지켰는지 마지막에 확인시키기

중요한 요청에는 완료 기준을 넣습니다.

```text
작성을 마치기 전에 다음을 확인해줘.
- 날짜, 시간, 회신 기한이 모두 들어 있는가?
- 정해지지 않은 장소나 링크를 만들지 않았는가?
- 본문이 7문장 이내인가?
```

이 확인은 1차 점검입니다. 실제 결과는 사용자가 다시 확인합니다.

## 조건이 너무 많다는 신호

다음 상황이라면 요청을 나누는 편이 낫습니다.

- 조건끼리 모순된다.
- 무엇이 가장 중요한지 알기 어렵다.
- 작성, 조사, 분석, 변환을 한꺼번에 요구한다.
- 결과를 확인할 기준이 너무 많다.

예를 들어 먼저 내용이 맞는 초안을 만든 뒤, 두 번째 요청에서 길이와 말투를 조정할 수 있습니다.

```text
먼저 내용의 누락이 없는 초안을 만들어줘. 아직 문장 길이는 줄이지 마.
```

```text
이제 날짜와 행동 요청은 유지하면서 본문을 7문장 이내로 줄여줘.
```
