# 원하는 결과를 더 정확하게 설명하기

> 상태: 초안

## 이번 장에서 할 일

“무엇을 해줘”에서 한 걸음 더 나아가 **누가, 왜, 어떻게 사용할 결과인지** 설명합니다.

## 결과부터 말해보세요

ChatGPT에게 세세한 작업 순서를 모두 지시하기 전에, 먼저 최종 결과를 설명합니다.

```text
회의 안내 이메일을 작성해줘.
```

이 요청에는 결과물의 종류만 있습니다. 다음 세 가지를 더하면 방향이 선명해집니다.

1. **독자:** 누가 읽는가?
2. **목적:** 왜 만드는가?
3. **기대 행동:** 읽은 사람이 무엇을 하길 바라는가?

```text
프로젝트에 참여하는 외부 고객에게 보낼 회의 안내 이메일을 작성해줘.
목적은 중간 점검 회의의 일정을 알리는 것이야.
고객이 참석 가능 여부를 회신하게 해줘.
```

## 같은 내용도 독자에 따라 달라집니다

같은 회의라도 읽는 사람이 누구인지에 따라 설명 수준과 말투가 달라집니다.

### 팀원에게

```text
우리 팀원에게 보낼 회의 공지를 작성해줘.
일정 변경과 각자 준비할 내용을 빠르게 확인할 수 있게 해줘.
```

### 외부 고객에게

```text
처음 함께 일하는 외부 고객에게 보낼 회의 안내 이메일을 작성해줘.
회의 목적을 짧게 설명하고 참석 가능 여부를 회신하도록 해줘.
```

### 경영진에게

```text
경영진에게 보낼 회의 요청 이메일을 작성해줘.
회의에서 내려야 할 결정과 참석이 필요한 이유를 첫 부분에 보여줘.
```

누가 읽는지 알려주는 것만으로도 어떤 정보를 앞에 둘지 달라집니다.

## 목적은 “작성”이 아니라 사용 이유입니다

“이메일을 작성한다”는 작업입니다. 목적은 그 이메일로 이루려는 변화입니다.

| 작업 | 가능한 목적 |
|---|---|
| 공지 작성 | 변경된 일정을 혼동 없이 알리기 |
| 보고서 요약 | 회의 전에 필요한 결정을 빠르게 파악하기 |
| 비교표 만들기 | 세 업체 중 다음 검토 대상을 고르기 |
| 회의록 정리 | 담당자와 마감일을 확정하기 |
| 교육자료 작성 | 처음 접하는 사람이 혼자 따라 하게 하기 |

목적이 다르면 좋은 결과의 기준도 달라집니다.

## 기대 행동까지 적기

업무 문서는 읽는 것으로 끝나지 않는 경우가 많습니다. 상대가 무엇을 해야 하는지 알려주세요.

```text
이메일을 읽은 사람이 10월 10일까지 참석 가능 여부를 답장하게 해줘.
```

```text
보고서를 읽은 부서장이 A안과 B안 중 하나를 선택할 수 있게 차이를 보여줘.
```

```text
회의록을 읽은 담당자가 자신의 할 일과 마감일을 바로 찾을 수 있게 해줘.
```

## 결과를 설명하는 네 칸

중요한 요청이라면 다음 네 칸만 채워도 좋습니다.

```text
만들 것: [결과물]
읽을 사람: [독자]
사용 목적: [왜 필요한가]
기대 행동: [읽은 뒤 무엇을 해야 하는가]
```

회의 안내 예시는 다음과 같습니다.

```text
만들 것: 회의 안내 이메일
읽을 사람: 프로젝트에 참여하는 외부 고객
사용 목적: 중간 점검 회의의 일정과 목적 안내
기대 행동: 10월 10일까지 참석 가능 여부 회신
```

이를 자연스러운 요청으로 합치면 됩니다.

```text
프로젝트에 참여하는 외부 고객에게 보낼 중간 점검 회의 안내 이메일을 작성해줘.
회의 일정과 목적을 분명히 알리고, 10월 10일까지 참석 가능 여부를 회신하게 하는 것이 목적이야.
```

## 모든 요청에 네 칸이 필요한 것은 아닙니다

간단한 질문에는 짧은 요청이면 충분합니다.

```text
이 문장을 더 짧게 바꿔줘.
```

그러나 다음과 같은 경우에는 결과를 더 정확히 설명하는 것이 좋습니다.

- 다른 사람에게 전달할 결과일 때
- 결과를 바탕으로 결정을 내려야 할 때
- 독자에 따라 표현이 크게 달라질 때
- 한 번의 결과로 업무 시간을 많이 줄이고 싶을 때

필요한 정보만 넣으세요. 길이가 길다고 반드시 좋은 요청은 아닙니다.

## 직접 해보기

1장에서 만든 첫 요청을 가져와 네 칸을 채웁니다.

| 항목 | 내 답 |
|---|---|
| 만들 것 |  |
| 읽을 사람 |  |
| 사용 목적 |  |
| 기대 행동 |  |

새 요청을 실행하고 첫 결과와 비교합니다.

### 비교 질문

- 중요한 내용이 더 앞에 나왔나요?
- 독자에게 맞는 설명과 말투가 되었나요?
- 결과가 성공했는지 판단하기 쉬워졌나요?
- 읽는 사람이 해야 할 행동이 분명한가요?

### 완료 체크

- [ ] 결과물을 구체적으로 말했다.
- [ ] 독자와 목적을 설명했다.
- [ ] 필요한 경우 기대 행동을 넣었다.
- [ ] 추가한 정보가 실제 결과를 어떻게 바꿨는지 확인했다.
