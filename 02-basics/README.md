# PART 2. 기본 사용법 익히기

완벽한 첫 질문을 외우기보다, 기본 요청을 대화로 개선하는 방법을 익힙니다.

## 이 Part를 사용하는 방법

일곱 장은 하나의 “회의 안내 이메일” 요청이 단계별로 좋아지는 과정으로 이어집니다. 각 장의 예시를 직접 실행하고, 결과가 어떻게 달라지는지 비교해보세요.

```text
일단 요청하기
→ 결과와 목적 설명하기
→ 맥락 추가하기
→ 조건 정하기
→ 결과 형태 지정하기
→ 예시로 기준 보여주기
→ 후속 대화로 수정하고 검증하기
```

모든 요소를 매번 사용할 필요는 없습니다. 결과를 실제로 바꾸는 정보만 골라 쓰는 것이 핵심입니다.
