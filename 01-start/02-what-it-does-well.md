# ChatGPT가 잘하는 것

> 상태: 초안

## 이번 장에서 할 일

ChatGPT가 도움을 주기 좋은 일을 기능 이름이 아니라 **업무 문제의 유형**으로 구분합니다.

이 장을 마치면 내 업무에서 ChatGPT로 먼저 시험해 볼 일을 세 가지 고를 수 있습니다.

## 먼저 기억할 기준

ChatGPT는 다음과 같은 일에 특히 유용합니다.

- 시작하기 어려운 일을 초안으로 빠르게 만들기
- 많은 내용을 정해진 기준으로 정리하기
- 같은 내용을 다른 독자나 형식에 맞게 바꾸기
- 여러 선택지와 관점을 만들어 생각을 넓히기
- 자료를 바탕으로 다음 산출물을 준비하기

결과가 글이 아니어도 괜찮습니다. 체크리스트, 표, 회의록, 보고서 구조, 발표 순서, 분석 질문처럼 **일을 진행하는 중간 산출물**도 만들 수 있습니다.

## 1. 처음부터 작성하기

빈 화면 앞에서 시작하기 어려울 때 초안을 맡겨 볼 수 있습니다.

### 이럴 때 써보세요

- 안내 이메일이나 공지 초안이 필요할 때
- 보고서의 첫 구조를 잡을 때
- 회의 안건이나 인터뷰 질문을 만들 때
- 발표의 이야기 흐름을 잡을 때

```text
신입사원 교육 참석자에게 보낼 안내 이메일 초안을 작성해줘.
교육은 9월 18일 오후 2시이고 장소는 3층 교육장이야.
준비물은 노트북이야. 친절하고 간결하게 써줘.
```

초안은 출발점입니다. 조직의 말투와 실제 일정은 사람이 확인합니다.

## 2. 이미 있는 글을 다듬기

내가 쓴 글의 의미는 유지하면서 길이, 말투, 구조를 바꿀 수 있습니다.

### 이럴 때 써보세요

- 장황한 글을 짧게 만들 때
- 딱딱한 문장을 쉽게 바꿀 때
- 고객용, 경영진용, 팀원용으로 말투를 바꿀 때
- 오탈자나 모호한 표현을 찾을 때

```text
아래 글의 핵심 의미와 수치는 그대로 유지해줘.
문장을 짧게 나누고, 비전공자가 이해하기 어려운 표현은 쉬운 말로 바꿔줘.
바꾼 내용 중 의미가 달라질 수 있는 부분은 따로 알려줘.
```

## 3. 요약하고 핵심을 뽑기

모든 요약은 목적에 따라 달라집니다. “짧게 요약해줘”보다 무엇을 위해 읽는지 알려주면 좋습니다.

### 이럴 때 써보세요

- 긴 보고서의 결론을 먼저 파악할 때
- 회의 메모에서 결정사항을 찾을 때
- 규정에서 내가 해야 할 행동을 뽑을 때
- 여러 의견의 공통점과 차이점을 정리할 때

```text
아래 회의 메모를 팀 공유용으로 요약해줘.
결정사항, 아직 결정되지 않은 사항, 담당자, 마감일을 구분해줘.
메모에 없는 담당자나 날짜는 추측하지 말고 “확인 필요”라고 표시해줘.
```

## 4. 분류하고 형태를 바꾸기

뒤섞인 정보를 같은 기준으로 정리하거나 다른 형식으로 변환하는 일입니다.

| 입력 | 바꿀 수 있는 결과 |
|---|---|
| 자유롭게 적은 메모 | 주제별 목록 |
| 고객 의견 | 칭찬·불편·요청 분류표 |
| 회의 기록 | 결정사항과 Action Item 표 |
| 긴 설명 | 체크리스트 |
| 보고서 | 발표자료 구성안 |

```text
아래 고객 의견을 기능, 가격, 사용성, 지원의 네 범주로 분류해줘.
둘 이상에 해당하면 모두 표시하고, 어느 범주에도 맞지 않으면 “기타”로 두어줘.
각 범주의 대표 의견을 한 문장으로 요약해줘.
```

## 5. 아이디어와 선택지 만들기

ChatGPT는 정답 하나를 고르는 것보다 여러 가능성을 빠르게 펼쳐 놓는 데 유용합니다.

### 잘 활용하는 순서

1. 조건 안에서 아이디어를 넓게 만든다.
2. 비슷한 아이디어를 묶는다.
3. 평가 기준을 정한다.
4. 기준에 따라 후보를 비교한다.
5. 사람이 상황에 맞는 후보를 고른다.

```text
팀원 12명이 참여하는 30분짜리 온라인 회고 방법을 8개 제안해줘.
별도 유료 도구 없이 할 수 있어야 하고, 말이 적은 사람도 참여하기 쉬워야 해.
먼저 다양하게 제안하고 아직 순위를 매기지는 마.
```

## 6. 비교하고 분석하기

자료가 있다면 공통 기준으로 비교하고 패턴이나 차이를 찾게 할 수 있습니다.

```text
첨부한 세 업체의 제안서를 가격, 일정, 지원 범위, 주요 위험의 기준으로 비교해줘.
제안서에 없는 정보는 “제공되지 않음”으로 표시하고 추측하지 마.
마지막에 결정을 위해 추가로 물어볼 질문을 업체별로 정리해줘.
```

여기서 ChatGPT가 내놓는 결론보다 **비교표와 추가 질문**이 더 유용할 때가 많습니다. 최종 선택에는 예산, 관계, 조직의 우선순위처럼 자료에 없는 맥락이 필요하기 때문입니다.

## 7. 배우고 설명받기

모르는 개념을 내 수준과 목적에 맞게 다시 설명해 달라고 할 수 있습니다.

```text
손익분기점을 처음 듣는 비전공자에게 설명해줘.
작은 카페를 예로 들고, 전문 용어가 나오면 바로 뜻을 풀어줘.
설명 뒤에는 이해했는지 확인할 수 있는 문제를 2개 내줘.
```

이해를 돕는 설명과 사실이 맞는 설명은 별개의 문제입니다. 중요한 학습 내용은 교재나 공식 자료와 대조합니다.

## 업무를 고를 때 쓰는 세 가지 질문

다음 질문에 “예”가 많을수록 첫 실험 대상으로 적합합니다.

1. 입력 자료와 원하는 결과를 설명할 수 있는가?
2. 결과를 사람이 검토하고 고칠 수 있는가?
3. 틀려도 바로 큰 피해가 생기지 않는가?

처음에는 고객에게 자동 발송되는 메시지보다 내가 검토할 내부 초안을, 최종 인사평가보다 평가 기준을 정리하는 일을 고르는 편이 좋습니다.

- [ ] 사람이 확인할 항목을 적었다.
